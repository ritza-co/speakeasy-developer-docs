This quickstart walks through building the simplest possible ChatGPT App that renders a custom widget.

## What you will build

A "Hello World" app that demonstrates the core concepts of the OpenAI Apps SDK:

- An MCP server with a single tool
- A widget resource that renders custom HTML in ChatGPT
- The `_meta` annotations that link tools to widgets

![Hello World widget rendered inside ChatGPT](/assets/docs/gram/img/functions/hello-world-widget.png)

## Prerequisites

To follow this guide:

- Node.js 22.18 or later
- pnpm (install with `npm install -g pnpm`)
- The [Gram CLI](/docs/gram/command-line/installation)
- A ChatGPT Plus, Pro, Business, Enterprise, or Education subscription (developer mode requires a paid subscription)

## Enable ChatGPT developer mode

Custom connectors require developer mode in ChatGPT:

- Open [ChatGPT](https://chatgpt.com).
- Navigate to **Settings → Apps → Advanced Settings**.
- Toggle **Developer mode** on.

<Callout title="Developer mode availability" type="warning">
  Developer mode requires a paid ChatGPT subscription. See the
  [OpenAI developer mode guide](https://platform.openai.com/docs/guides/developer-mode)
  for the latest availability details.
</Callout>

## Understand the MCP server

The entire app lives in `src/mcp-server.ts`. Open the file to see the key components.

### The widget HTML

The widget is a simple HTML page with inline styles:

```typescript
const WIDGET_HTML = `<!DOCTYPE html>
<html>
<head>
  <style>
    .hello-widget {
      font-family: system-ui, sans-serif;
      padding: 24px;
      border-radius: 12px;
      background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
      color: white;
      text-align: center;
    }
    .hello-widget h1 { margin: 0 0 8px 0; font-size: 28px; }
    .hello-widget p { margin: 0; opacity: 0.9; }
  </style>
</head>
<body>
  <div class="hello-widget">
    <h1>👋 Hello, World!</h1>
    <p>This widget is rendered by the OpenAI Apps SDK</p>
  </div>
</body>
</html>`;
```

### The OpenAI metadata

The `_meta` object tells ChatGPT how to handle the tool and render the widget:

```typescript
const widgetMeta = {
  "openai/outputTemplate": WIDGET_URI,           // Links tool to widget resource
  "openai/toolInvocation/invoking": "Loading...", // Status while tool runs
  "openai/toolInvocation/invoked": "Done!",       // Status when complete
  "openai/widgetAccessible": "true",
  "openai/resultCanProduceWidget": "true",
};
```

### The MCP server

The server exposes one tool (`hello`) and one resource (the widget HTML). Note that resources require a `description` field for Gram to discover them, and a `ListResourceTemplatesRequestSchema` handler:

```typescript
export function createHelloServer(): Server {
  const server = new Server(
    { name: "hello-world", version: "0.1.0" },
    { capabilities: { resources: {}, tools: {} } }
  );

  // List widget resources
  server.setRequestHandler(ListResourcesRequestSchema, async () => ({
    resources: [{
      uri: WIDGET_URI,
      name: "Hello Widget",
      description: "Hello Widget markup",
      mimeType: "text/html+skybridge",
      _meta: widgetMeta,
    }],
  }));

  // Return widget HTML when requested
  server.setRequestHandler(ReadResourceRequestSchema, async (request) => {
    if (request.params.uri !== WIDGET_URI) {
      throw new Error(`Unknown resource: ${request.params.uri}`);
    }
    return {
      contents: [{
        uri: WIDGET_URI,
        mimeType: "text/html+skybridge",
        text: WIDGET_HTML,
        _meta: widgetMeta,
      }],
    };
  });

  // List resource templates (required for Gram to discover resources)
  server.setRequestHandler(ListResourceTemplatesRequestSchema, async () => ({
    resourceTemplates: [{
      uriTemplate: WIDGET_URI,
      name: "Hello Widget",
      description: "Hello Widget markup",
      mimeType: "text/html+skybridge",
      _meta: widgetMeta,
    }],
  }));

  // List available tools
  server.setRequestHandler(ListToolsRequestSchema, async () => ({
    tools: [{
      name: "hello",
      description: "Show a hello world widget",
      inputSchema: { type: "object", properties: {}, additionalProperties: false },
      _meta: widgetMeta,
      annotations: { readOnlyHint: true, destructiveHint: false, openWorldHint: false },
    }],
  }));

  // Handle tool call
  server.setRequestHandler(CallToolRequestSchema, async (request) => {
    if (request.params.name !== "hello") {
      throw new Error(`Unknown tool: ${request.params.name}`);
    }
    return {
      content: [{ type: "text", text: "Hello, World!" }],
      _meta: widgetMeta,
    };
  });

  return server;
}
```

## Build and deploy

Build the function and deploy to Gram:

```bash
pnpm build
gram auth
pnpm push
```

After the push completes, the Gram dashboard displays the hosted MCP endpoint.

## Create a toolset and MCP server

In the Gram dashboard:

- Create a new **Toolset** and give it a name like "Hello World".
- Add the `hello` tool from the deployed function.
- Add the `ui://widget/hello.html` resource.
- Navigate to **MCP**, click the toolset, and click **Enable**.
- Set the visibility to **Public**.

Copy the MCP endpoint URL for the next step.

## Add the connector to ChatGPT

In ChatGPT:

- Navigate to **Settings → Apps**.
- Click **Create**.
- Paste the Gram MCP endpoint URL.
- Give the connector a name and click **Create**.

## Test the app

Open a new chat in ChatGPT, click the **+** button, and add the connector. Ask ChatGPT to say hello.

The widget should appear inline in the conversation.

## Next steps

This example demonstrates the minimal structure of an OpenAI App. To build more complex apps:

- Add input parameters to tools and pass data to widgets via `structuredContent`
- Access data in widgets using `window.openai.toolOutput`
- Build interactive widgets with React or other frameworks

For a more complete example with interactive maps and dynamic data, see [Using the OpenAI Apps SDK with Gram Functions](/docs/gram/examples/open-ai-apps-sdk).
