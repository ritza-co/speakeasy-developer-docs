Consumer Tools
ChatGPT (OpenAI Chatbot): A conversational AI assistant (now powered by GPT-5) for general Q&A, writing, and research[1]. It runs as a web app (chat.openai.com) and is offered in free and paid tiers (Plus, Pro) with progressively faster models and added features[2][1]. Primary uses include information retrieval, content creation, tutoring and brainstorming. Target audience is everyday users, students and professionals. Availability: via web browser, official mobile apps (iOS/Android)[3], desktop apps (macOS, Windows)[4], and as a chatbot plugin for the new ChatGPT Atlas browser[5][4].
ChatGPT Atlas (Browser): A dedicated web browser with ChatGPT built in[5]. Atlas provides a sidebar ChatGPT interface on every page, so it can answer questions about what you’re viewing and “take action” via agent mode (e.g. filling forms, summarizing pages)[5]. Use cases include research, shopping assistance, and automated workflows while browsing. It is aimed at consumer and business users who want AI assistance in-context. Availability: macOS app (with Windows, iOS/Android forthcoming)[5] (currently in preview for free, Plus, Pro, Business, Enterprise, and Education plans).
ChatGPT Mobile/Desktop Apps & Extensions: Official ChatGPT mobile apps allow voice chat and image queries (e.g. ask about photos) on the go[3]. The desktop apps (Windows/macOS) and Chrome extension embed ChatGPT into your OS or browser, letting you chat about emails, screenshots or any on-screen content[4]. Primary uses mirror the web ChatGPT. Availability: iOS and Android app stores[3], desktop downloads on OpenAI’s site[4], and Chrome browser extension.
Custom GPTs: User-created “GPT” assistants in ChatGPT. Plus and Pro users can build specialized chatbots by providing instructions, examples or documents (e.g. a resume helper, book recommender)[6]. Use cases include personalized tutoring, roleplay agents, or domain-specific assistants. Targeted at end-users and organizations who want tailored AI agents. Availability: in the ChatGPT interface for Plus/Pro users[6].
Developer APIs and Tools
OpenAI API Platform: A suite of web APIs giving programmatic access to OpenAI’s models and services. Includes Chat/Completion APIs (accessing models like GPT-5, GPT-4, GPT-3.5, etc.), Text Completions API, DALL·E (Image) API, Whisper (Speech) API, Embeddings API, Moderation API, Fine-tuning API, and more. Use cases span chatbot backends, content generation, semantic search, classification, etc. Audience is developers and enterprises building AI applications. Availability: via OpenAI’s cloud API (platform.openai.com) with REST endpoints and official SDKs (e.g. Python, Node). The latest GPT-5 models (Pro/Reasoning/mini/nano) are available through these APIs[7], and the ChatCompletion API uses the same model family as ChatGPT[8].
GPT Model APIs: Language model endpoints for different purposes. For conversation, the ChatCompletion API (models gpt-5, gpt-4.1, gpt-4o, gpt-3.5-turbo, etc.) generates chat-style responses. The Completions API (text-only models) also remains available. A new Assistants API format (being unified with the Responses API) helps orchestrate multi-turn tasks. Use cases: building custom chatbots, assistants and dialog systems. Audience: developers. Availability: via the OpenAI API (pay-as-you-go).
Embeddings API: Converts text into numerical vectors for search, clustering, or recommendation. Use cases include semantic search, document retrieval, and similarity matching. Audience: developers. Availability: via text-embedding endpoints on the API.
Fine-tuning API: Allows adapting base models (like GPT-4 or GPT-5 mini) to custom data. Use cases: specialized chatbots or content generation. Audience: developers, enterprises. Availability: via the API (designate fine-tuning jobs and use fine-tuned model IDs).
Batch API: An asynchronous API (in beta) for large-volume text tasks. Use cases: offline processing of big datasets. Audience: enterprise developers. Availability: via OpenAI’s API (beta, document lookup).
Functions and Tools (API feature): Developers can define function calls that models invoke, allowing safe integration with external systems. Built-in tools like web search, file browsing, Python execution (Advanced Data Analysis), and function calling enhance the API’s capabilities. Audience: developers building agentic or complex systems. Availability: via ChatCompletion endpoints with the function-calling protocol.
Realtime API: A new low-latency, multimodal API for voice and live interaction[9][10]. Supports speech-to-speech (single-model voice conversations), audio input/output, and (recently added) image input. Use cases: real-time voice assistants (customer support bots, virtual agents). Audience: developers/enterprises building voice agents. Availability: via the gpt-realtime endpoints on the API. The gpt-realtime model delivers natural-sounding speech and supports two new voices (Marin and Cedar)[10].
Codex (AI Coding Assistant): An AI agent specialized for software development[11]. Included with ChatGPT Plus/Pro/Business/Enterprise, Codex can be used via a CLI (npm i -g @openai/codex), IDE extensions (VSCode, Cursor, Windsurf), or Slack/GitHub integration[12]. It can edit code, run commands, generate pull requests, and review code. Use cases include pair programming, automated code review, and CI/CD automation[12]. Audience: developers and engineering teams. Availability: as an integrated ChatGPT feature and standalone tools (CLI, IDE plugin, web dashboard).
OpenAI Playground: A web-based UI for experimenting with OpenAI’s models. Developers and researchers use it to prototype prompts and chat, test model parameters, and browse example use cases. Audience: Developers and researchers. Availability: on the OpenAI site (no coding required).
Developer SDKs and Tools: Official libraries (Python, Node.js, etc.) and a CLI for interacting with the API. These simplify tasks like calling APIs, handling authentication, and processing responses. Audience: Developers. Availability: OpenAI maintains SDKs on GitHub and package registries (e.g. PyPI, npm).
Agent & Workflow Tools
AgentKit: A comprehensive agent-building toolkit introduced in 2025. It includes a visual Agent Builder (for designing agent workflows), ChatKit (for embedding chat-based UIs), a Connector Registry (management UI for integrations like databases or internal tools), an open-source Evals framework, Guardrails safety tooling, and Reinforcement Fine-Tuning for customizing agent reasoning. Use cases: creating multi-step AI agents (e.g. virtual assistants that integrate with company data and tools) and deploying them to production. Audience: developers and enterprises. Availability: Access via the OpenAI platform; pricing is free in preview until late 2025.
Responses API (Agents API): A new endpoint that combines chat completions with built-in tools for retrieval and action[13]. It simplifies building “agents” by allowing a single API call to invoke web search, file lookup, and other tools in the conversation. Use cases: creating assistants that can automatically gather information or perform tasks across tools. Audience: developers. Availability: part of the OpenAI API platform; priced by model usage (no separate fee)[14][13].
Agents SDK: A software development kit for building and deploying agents on OpenAI’s platform[15]. It works with both the new Responses API and standard chat endpoints, and lets developers programmatically define agent logic in Python (with Node.js support coming). Use cases: coding agent flows, integrating LLM reasoning into apps. Audience: developers. Availability: Open-sourced on GitHub and integrated with the API.
Built-in Tools: APIs include first-class tools like web search and file browsing. These tools can be called by models within the Responses/Chat API. Use cases: agents that need up-to-date info or internal data access. Audience: developers. Availability: via the API; pricing is per use (e.g. $10 per 1k web searches)[16].
Speech/Audio Tools
Whisper (Speech-to-Text API): An automatic speech recognition model that transcribes audio[17]. It can produce transcripts in the source language or translate to English, with very high accuracy. Use cases: transcribing podcasts, calls, or voice notes. Audience: developers. Availability: via the OpenAI API (/audio/transcriptions for transcription, /audio/translations for translation)[17].
Realtime API (Speech-to-Speech): A unified voice-agent API powered by the gpt-realtime model[10]. It takes audio input (speech) and generates audio output directly, without separate ASR/TTS steps. The model understands context, follows instructions, and now speaks in high-quality voices (e.g. “Marin” and “Cedar”)[10]. Use cases: voice assistants, IVR systems, or real-time translation. Audience: developers, enterprises. Availability: via the OpenAI API (see Realtime endpoints)[10].
Audio Translation and Analysis: Built on Whisper, the API can translate speech to English on the fly and handle multilingual input. Use cases: language learning apps, transcription of foreign-language media. Availability: through the Whisper translation endpoint as part of the audio API.
Image/Multimodal Tools
DALL·E 3 (Image Generation): OpenAI’s latest text-to-image model[18][19]. Given a text prompt, DALL·E 3 generates high-fidelity, detailed images, and allows iterative refinement via chat. Use cases: creative image generation, design prototypes, content creation. Audience: consumers (via ChatGPT) and developers. Availability: directly in ChatGPT (Plus and Enterprise users)[18] and via the OpenAI API (using the dall-e-3 model)[20].
GPT-Image API (Image Gen): An API (using models like GPT-image-1) for generating or editing images from text prompts[21]. It offers fine-grained control (resolution, style) and supports both landscape and portrait modes. Audience: developers. Availability: via the OpenAI API (choose the gpt-image-1 model in the image generation endpoint)[21].
Sora (Text-to-Video): A video generation model that creates short videos from text descriptions[22][23]. Sora can render dynamic scenes, complex camera motion, and multiple characters. Use cases: quick video storyboarding, creative content, marketing. Audience: creators and advanced users. Availability: rolled out via Sora.com and integrated into ChatGPT for Plus/Pro users[24][25]. (Plus users get 50 short videos/month; Pro users get higher resolution, longer videos[25].)
Vision Features (GPT-4o Vision): GPT-4 (and its successors like GPT-4o) support image inputs. In ChatGPT, users can upload photos for captioning, analysis or Q&A. Use cases: visual Q&A, document analysis. Audience: general users. Availability: in ChatGPT apps; on the API by sending image files to GPT-4o models.
Enterprise Features
ChatGPT for Teams/Business/Enterprise: Enhanced versions of ChatGPT tailored for organizations. Business (for small teams) and Enterprise plans include unlimited GPT-5 access, longer context windows, and integration of company knowledge bases (e.g. Slack, Google Drive)[26]. They add admin controls (SSO, RBAC, audit logs), data encryption and compliance (SOC2, ISO, GDPR)[26][27]. Use cases: secure company-wide AI assistant, automated analytics, coding assistance at scale. Audience: enterprises, startups. Availability: via subscription (see OpenAI for pricing).
Data & Security Controls: Enterprise plans offer features like data residency, custom retention policies, and the guarantee that user data won’t be used for training customer models by default[28]. Compliance features (SSO, SCIM, EKM, domain verification) are included[27]. These tools support use cases in regulated industries.
Priority Processing & Scale Tier: For high-volume enterprise users, OpenAI offers priority throughput, dedicated compute (Scale Tier), and reserved capacity agreements to ensure performance and uptime. Use cases: latency-sensitive apps, mission-critical automation. Audience: large enterprises. Availability: via special enterprise contracts (contact sales)[29].
Azure OpenAI Service (Partner Platform): Microsoft’s Azure platform offers OpenAI models (e.g. GPT-4, embeddings) under its own API for enterprise customers with Azure integration (Active Directory, compliance, etc.). Though a Microsoft product, it provides another way for enterprises to consume OpenAI technology.
Advanced Data Analysis (Code Interpreter): A built-in tool in ChatGPT (formerly “Code Interpreter”) available to Plus/Pro/Enterprise. It can run code on uploads to analyze data, visualize, and automate tasks. Use cases: data analysis, report generation. Audience: analysts, enterprise users. Availability: in ChatGPT web and apps for paid tiers.
Research / Advanced Models
GPT-5 (Reasoning, Pro, Mini, Nano): OpenAI’s latest large language model family, with “Pro” for reasoning tasks and “Mini/Nano” lightweight variants[7]. It underpins ChatGPT and the API’s best offerings. Use cases: state-of-the-art text generation, coding, reasoning. Audience: researchers, developers, enterprises. Availability: via the API platform (as of 2024)[7].
GPT-4.5 / GPT-4o / GPT-4.1: Intermediate and specialized models (e.g. GPT-4.5 for improved intelligence tasks, GPT-4o for voice/vision with real-time capabilities). Use cases: research, advanced development (these may appear in research or limited release). Audience: researchers, select developers. Availability: selectively on the API or research previews (as OpenAI releases them).
Open Models & Code: OpenAI has released some models to the community, such as Whisper (open-sourced ASR model) and CLIP (image-text embedding model). These are used by researchers and hobbyists. Availability: via GitHub (e.g. openai/whisper and openai/clip).
Evals (Evaluation Framework): An open-source toolkit for benchmarking and evaluating models and agents. Researchers can write “evaluator” code to test model performance on tasks. Audience: AI researchers and developers. Availability: on GitHub (openai/evals).
Guardrails Library: An open-source Python framework for constraining and steering LLM outputs (e.g. checking format or filtering content). Used in AgentKit and by developers to enforce reliability. Audience: developers building safe agents. Availability: on GitHub (openai/guardrails).
